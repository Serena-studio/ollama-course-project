# ollama-course-project

开源创新思维课程 · Ollama 项目

> ⚠️ **合成演练声明**：本仓库所有业务事实（企业名称、人物、指标、访谈记录等）均为课程演练的**合成场景**，不代表真实授权、业务执行或客户验收。公开业务方向有来源，访谈事实为演练创作。

## 项目简介

本项目围绕一个合成演练场景——**上海外综服国际贸易有限公司 · 进出口代理单证一致性**——产出课程作业。目标是通过业务发现与访谈，梳理出一套“代理单证一致性智能体系统”的需求与技术方案，核心交付物为：**一页缺项清单 + 对应来源位置（定位到原单据字段）**，供人工确认使用。

业务链路：客户提供 → 单证检查 → 人工确认 → 委托作业 → 归档。

当前仓库为**文档与演练资料交付阶段**，包含客户简报、访谈问题库、现场调研、业务挖掘、需求发现报告以及技术方案等；智能体系统的可运行代码尚未提交到本仓库（见文末“当前进度与已知缺口”）。

## 文件说明

| 文件 | 用途 |
|------|------|
| `客户简报.html` | 演练背景、客户提出的问题、需核实的角色诉求，项目的起点 |
| `业务发现访谈问题库.html` | 面向六个角色的访谈问题清单 |
| `利益相关者资料与分工.html` | 六名角色的职责与分工地图 |
| `现状信息请求表.html` | 调研阶段需向现场索取的信息清单 |
| `现状流程图与异常路径.html` | 现状业务流程图及异常路径标注 |
| `进出口代理单证一致性-现场调研报告.md` | 现场调研阶段的产出（阶段状态：已完成） |
| `进出口代理单证一致性-业务挖掘报告.md` | 业务挖掘练习的原始导出（标注“未确认、得分 0.0”） |
| `进出口代理单证一致性-业务挖掘报告 (1).md` | 业务挖掘报告的完善版本（含评分与参考答案） |
| `discovery-report (1).md` / `.csv` / `.json` | 业务需求发现报告的三种格式，含六项结论与证据缺口 |
| `docs/技术方案.md` | 智能体系统的完整技术方案：需求要点、数据红线、架构、数据模型、接口、分阶段计划 |
| `docs/开发指令模板-完善版.md` | 补全后的开发指令，可直接用于驱动 AI 工程师开发系统 |

## 推荐阅读顺序

1. `客户简报.html` — 了解演练背景与初始诉求
2. `现状流程图与异常路径.html` → `现状信息请求表.html` — 理解现状与调研范围
3. `进出口代理单证一致性-现场调研报告.md` — 看现场调研产出
4. `进出口代理单证一致性-业务挖掘报告 (1).md` — 看业务机会挖掘与评分
5. `discovery-report (1).md` — 看最终的六项需求结论（P0/P1）与证据缺口
6. `docs/技术方案.md` — 看系统如何落地（数据红线、架构、接口、分阶段计划）
7. `docs/开发指令模板-完善版.md` — 若要启动开发，以此为指令入口

## 本地查看方式

- **HTML 文件**：直接用浏览器双击打开即可（支持打印或另存为 PDF）。
- **Markdown 文件**：用支持 Markdown 渲染的编辑器（如 VS Code、Typora）打开查看。
- **CSV / JSON**：`discovery-report.csv` 可用表格软件打开；`discovery-report.json` 可用文本编辑器或在线 JSON 工具查看。
- 本仓库**暂无可运行代码**，无需安装依赖；如需启动智能体系统，请先确认代码是否已提交（见下）。
